# Ritvik Edoliya Portfolio

A personal portfolio website built with [Hugo](https://gohugo.io/) and the [Blowfish](https://blowfish.page/) theme, featuring a custom navy blue color scheme.

## Getting Started

### Prerequisites

- [Hugo Extended](https://gohugo.io/installation/) (v0.117.0 or later)

### Setup

1. Clone the repository with submodules:
   ```bash
   git clone --recurse-submodules https://github.com/Ritvik179/Ritvik_Edoliya_Portfolio.git
   ```

2. Start the development server:
   ```bash
   hugo server
   ```

3. Open your browser at `http://localhost:1313/`

### Build

To build the static site:

```bash
hugo
```

The output will be in the `public/` directory.
